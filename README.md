# 페르소나 매니저 (Persona Manager)

SillyTavern 페르소나가 수십 개로 늘어나면 목록을 왔다갔다하며 찾기가 어려워집니다.
이 확장은 **얼굴로 찾고, 태그로 묶고, 한 번에 바꾸는** 두 개의 화면을 더합니다.

ST 원본 파일은 한 줄도 고치지 않습니다.

## 화면 두 개

| 여는 곳 | 화면 | 하는 일 |
|---|---|---|
| 입력창 왼쪽의 내 얼굴 버튼 | **빠른 전환창** | 검색·태그 칩으로 걸러 얼굴을 골라 바로 전환 |
| 요술봉 메뉴 → 페르소나 매니저 | **관리 화면** | 태그 달기·일괄 작업·이름/설명 편집 |

전환창 하단의 `관리 화면 열기 ↗` 로 서로 오갈 수 있습니다.

## 기능

- **태그** — 한 페르소나에 여러 개. 만들기·이름 바꾸기·색·삭제. 칩을 여러 개 고르면 **교집합**으로 걸러집니다.
- **즐겨찾기 ★ 와 최근 5개** — 최근은 페르소나를 바꿀 때마다 자동으로 기록됩니다.
- **현재 사용 중 표시** — 금색 테두리와 작은 표시.
- **보기 토글** — 목록 / 작게 / 크게. 고른 모드를 기억합니다.
  - 어느 보기에서든 얼굴을 누르면 세부창이 열려 이름·설명·태그를 바로 수정합니다.
  - 목록·작게: 체크칸으로 여러 개 골라 하단 바에서 태그 일괄 달기/빼기·즐겨찾기
  - 카드마다 ★ 로 즐겨찾기를 바로 켜고 끕니다(전환창 포함).
- **정리용 조건** — 태그 없음 / 설명 빔 / 로어북 붙음
- **원래 페르소나 탭 끼워넣기** — 검색창 아래 태그 칩 박스(원래 목록이 그대로 걸러집니다) + 현재 페르소나 이름 옆 ★ 와 태그
- **모바일 지원** — 좁은 화면에서는 관리 화면이 전체 화면으로 열리고, 세부창은 `← 목록` 으로 돌아옵니다.

## 설계 원칙

- **전환·개명·설명 수정은 ST 원래 경로로만 합니다.** 설정(`power_user.personas` 등)을 직접 쓰면
  ST 핸들러에 붙어 있는 파생 처리(저장·이벤트·목록 재렌더·토큰 카운트)가 통째로 빠집니다.
  - 전환 → `setUserAvatar()`
  - 현재 페르소나 설명 → 원래 입력칸 `#persona_description` 을 대리 조작
  - 그 외(이름, 비현재 페르소나 설명) → ST가 등록해 둔 `/persona-update` 콜백을 레지스트리에서 꺼내 호출
- **원래 탭 필터는 ST 자신의 `personasFilter` 에 필터 함수를 한 개 얹는 방식**입니다.
  목록을 눈으로 숨기는 게 아니라 ST 필터 파이프라인에 참여하므로 페이지네이션 개수가 맞고
  재렌더 후에도 유지됩니다.
- 끼워넣기는 전부 `try/catch` 로 감쌌습니다. 실패해도 ST 원래 탭은 그대로 동작합니다.
- 저장은 `extension_settings.persona_manager` → ST 서버 설정이라 기기 공통입니다.
- 목록은 ST 페르소나 패널과 같은 기준(아바타 파일 목록)으로 만듭니다. 지워진 페르소나는 보이지 않습니다.
- 페르소나가 지워지면 남은 태그·즐겨찾기·최근 기록을 자동으로 치웁니다. 파일 목록을 못 불러온 경우엔 태그가 통째로 지워지지 않도록 정리를 건너뜁니다.

## 파일

```
persona-manager/
├── manifest.json
├── index.js              진입점 · 버튼/메뉴 설치 · 이벤트 구독
├── style.css
└── src/
    ├── settings.js       설정 스키마 · 태그/즐겨찾기/최근 순수 로직
    ├── filters.js        검색 · 태그 교집합 · 정리용 조건 (순수 로직)
    ├── st-bridge.js      ST 배관 어댑터 (읽기 · 전환 · 편집)
    ├── window.js         떠 있는 창 뼈대 (드래그 · 접기 · z-index) — 재사용용
    ├── ui-parts.js       칩 · 카드 · 태그 메뉴
    ├── switcher.js       빠른 전환창
    ├── manager.js        관리 화면
    └── tab-inject.js     ST 원래 페르소나 탭 끼워넣기
```

`src/window.js` 는 ST 의존성이 0입니다 — 다른 확장에서 그대로 가져다 쓸 수 있습니다.

## 설치

1. SillyTavern 상단 **확장(🧩) → Install extension**
2. 주소 칸에 `https://github.com/athenawin00-boop/persona-manager` 를 넣고 설치
3. 브라우저 새로고침 → 입력창 왼쪽에 내 얼굴 버튼이 보이면 성공입니다.

클라이언트 확장이라 서버 재시작은 필요 없습니다.
